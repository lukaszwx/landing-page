# 🚀 Landing Page — Front-end Premium

Landing page moderna desenvolvida com foco em **performance, design e experiência do usuário**, utilizando animações avançadas e identidade visual minimalista em preto e branco.

---


## 🧠 Sobre o projeto

Este projeto foi criado com o objetivo de simular uma **landing page real de produto/serviço**, aplicando boas práticas de:

* UI/UX Design
* Animações com GSAP
* Estruturação semântica
* Código limpo e escalável

A proposta é fugir de layouts genéricos e entregar uma interface com **identidade forte e sensação de produto premium**.

---

## ⚙️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)
* GSAP (GreenSock Animation Platform)

---

## ✨ Funcionalidades

* 🎯 Hero section com animação em timeline
* ⚡ Loader animado na entrada
* 🧩 Scroll reveal com blur e suavização
* 🖱️ Cursor customizado
* 🎴 Cards com interação 3D
* 🌌 Background com grid + noise (efeito premium)
* 🔘 Botões com micro-interações avançadas

---

## 🎨 Conceito de design

O projeto segue uma linha visual:

* Preto & branco (minimalismo)
* Alto contraste
* Tipografia limpa
* Micro-interações sutis
* Sensação de produto moderno (inspirado em startups como Vercel e Stripe)
